# SoulPrint UI reference

The supplied product document includes visual references and is the source of truth for the initial experience.

- Dark near-black/navy surfaces with a star-field and nebula backdrop.
- Cyan, violet, pink and soft-lilac glow; use contrast-safe text rather than relying on glow for status.
- Large elegant serif headings paired with compact sans-serif interface text.
- Rounded translucent panels, pill controls, icon-led navigation and low-key gradients.
- Desktop uses a persistent left rail. Mobile collapses it into an accessible bottom/navigation trigger without losing primary journeys.

The repository uses an original generated nebula asset at `apps/web/public/images/soulprint-nebula.png`; no reference portraits are copied into the application.
